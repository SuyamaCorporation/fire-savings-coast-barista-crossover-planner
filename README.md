# FIRE段階別 Coast/Barista FIRE 資産残高プランナー

年齢・資産・積立額・利回り・生活費を入力し、Full FIRE / Coast FIRE / Barista FIRE の3戦略でいつ達成できるかを比較するプランナー。

## 機能

- Full FIRE（年間支出×25倍）・Coast FIRE・Barista FIRE の目標額を自動算出
- 各戦略のクロスオーバーポイント（達成年齢・資産額）を比較表で表示
- SVG 棒グラフで年齢別資産推移を可視化（目標ライン重ね表示）
- 年別詳細テーブルで各 FIRE ステージの達成状況を確認
- 入力値を localStorage に自動保存・次回起動時に復元
